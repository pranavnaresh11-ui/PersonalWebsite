About

I'm a student in Cary, North Carolina, doing independent robotics research alongside dual-enrollment college coursework. Most of what I study I build first: I design the hardware, wire it and test it, then write the code that measures what it does.

My current focus is gait adaptation in tensegrity robots, and an optical sensor called Mirage that I'd like to make small and inexpensive enough to be useful in manufacturing. I'm drawn to problems where the mechanics, the electronics and the software all have to be right at once.

Research & Work

Everything here is built from the circuit board up.

Tensegrity Locomotion2026 A vibration-driven tensegrity robot that tunes its own gait with Bayesian optimization. Computer vision tracking and IMU telemetry measure every trial, so it can adapt as the ground beneath it changes.

The goal is cross-terrain gait adaptation: one robot, with no wheels or legs, finding an efficient way to move over surfaces it was never tuned for. A longer write-up and the code will be linked here.

Mirage Optical Sensor2026 A modular Background-Oriented Schlieren imaging system paired with an edge-AI model. It makes thermal plumes and shielding-gas defects visible, so problems in manufacturing can be caught as they happen.

Schlieren imaging reveals small changes in how air bends light. Mirage puts the technique into inexpensive, modular hardware and runs detection on the device itself. Build notes and results will be linked here.

Applied AI & Full-Stack Systems2025 Web and mobile tools built end to end in TypeScript, React, Python and C++. Most began as something my own research needed.

Selected projects will be listed here. In the meantime, the code is on GitHub.
